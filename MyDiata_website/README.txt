MyDiata Limited website - upload guide

WHAT THIS IS
Plain HTML files. No software is needed to run them. Open index.html in a browser to preview.

TO PUT IT ONLINE (free options)
1. Cloudflare Pages: create an account, choose "Create a project", then "Upload assets", and drag in the whole MyDiata_website folder (the files inside, not the zip).
   Netlify: go to app.netlify.com/drop and drag the folder onto the page.
2. Connect your own domain (for example mydiata.com.ng) in the host's "Custom domains" settings. The host shows the DNS records to add at your domain registrar.

TO CHANGE TEXT
Open the page (for example about.html) in any text editor, find the wording and edit it. Keep the tags around it as they are.
